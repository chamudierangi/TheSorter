# 📊 Sorting Algorithm Visualizer (`TheSorter`)

An interactive, web-based educational tool designed to help users intuitively understand how different sorting algorithms operate step-by-step through real-time visual animations and numerical data tracking.

![Project Banner](https://img.shields.io/badge/Status-Active-brightgreen) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) ![License](https://img.shields.io/badge/License-MIT-blue)

---

##  Key Features

* **Multiple Sorting Algorithms:** Support for foundational and advanced sorting techniques:
  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Merge Sort
  * Shell Sort
* **Custom Array Input:** Flexibility to input custom comma-separated numerical datasets or generate random arrays dynamically.
* **Interactive Visualizations:** Dynamic bar charts that change heights and color-code states (comparing, swapping, and sorted partitions) instantly.
* **Granular Speed Control:** Adjustable animation speed slider for fast-paced overviews or slow-motion step-by-step analysis.
* **Execution Control & Safety:** Full playback control with a dedicated **Stop** button to halt ongoing sorting processes safely at any moment.
* **Live Text Tracking:** Real-time textual display of array elements reflecting state transformations instantly alongside visual bars.
* **Completion Feedback:** Success notification banners and visual color transformations upon successful sorting completion.

---

##  Technology Stack

* **Frontend Structure:** HTML5
* **Styling & UI:** Custom CSS3 (Dark-themed glassmorphism interface optimized for readability and modern aesthetics)
* **Logic & Animation:** Vanilla JavaScript (ES6+) utilizing asynchronous functions (`async/await`) and delays to manage real-time UI rendering frames without blocking the main thread.
